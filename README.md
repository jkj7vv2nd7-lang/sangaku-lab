# 算額ラボ（Sangaku Lab）〜和算でひらめく探究ノート〜

日本の伝統数学「算額」をテーマにした、教育・学習用の単一HTML Webアプリです。インストール不要、ブラウザだけで動きます（オフライン対応・外部通信なし）。

公開ページ： https://jkj7vv2nd7-lang.github.io/sangaku-lab/

## 3つのモード

- **生徒用：算額に挑戦！** — 算額3問（Lv.1 正方形と円と三角形／Lv.2 直角三角形と内接円／Lv.3 大円に接する4つの小円）。スライダーやドラッグで図形が動き、「変わらない比」に気づく観察メモ、補助線お絵描きツール、3段階ヒント（着眼点／補助線／式の立て方）。正解すると朱色の「奉納・解決済」御朱印スタンプと視覚解説アニメ。解いた印は「御朱印スタンプ帳」に集まります。ふりがな切替・効果音（ミュート可）付き。
- **先生用：授業ダッシュボード** — 一斉提示モード（補助線・答えの表示切替、全画面）、ワークシート自動生成（生徒用／先生用、A4縦1枚・5cm実寸確認線つき）、擬似クラス進捗モニター（デモ表示・ダミーデータ）。
- **オリジナル算額メーカー** — 正方形・円・正三角形・補助線を配置して問題文と答えを設定し、オリジナル絵馬を作成。作った算額は生徒用で解くことも、ワークシートにすることもできます。

## 仕様

- 図形・問題文・答えはすべて同じパラメータから計算されるため、図と数値が食い違いません。
- 数式は教科書表記（横棒の分数、上線がつながった根号、セリフ体イタリックの変数）で自前組みしています。
- 記録（解決済み・自作算額・設定）は端末内の localStorage にのみ保存され、外に送られることはありません。アカウント不要です。
- 進捗モニターはデモ表示で、実際の児童・生徒のデータは集めていません。
